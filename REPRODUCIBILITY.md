# Reproducibility scope

This archive supports manuscript/source verification, figure regeneration, source traceability, and selected deterministic helper operations. It is not described as a complete end-to-end reproduction of every historical calculation when the original analysis object is unavailable.

## Included

- Main and supplementary LaTeX sources
- Final manuscript figure assets
- Figure-generation script
- Saudi-center target-status CSV
- Saudi target-extraction helper
- Reference audit
- Manuscript PDFs
- SHA-256 manifest

## Explicitly not included / not claimed

- Original publisher-hosted PLOS S1 XLS binary
- Original GSE97358 raw-count object used for any donor-blocked negative-binomial sensitivity
- Original four-family timing-model specification file
- Third-party raw GEO/ArrayExpress datasets

## Consequence for claims

The manuscript therefore does not claim independent re-extraction of the Saudi TGFB1/CTHRC1 rows, a newly rerun donor-blocked negative-binomial coefficient, or a newly reconstructed four-family timing-model comparison.
